02. Layout & Navigation

Vertical Navigation

The primary navigation always resides on the left in a 256px fixed sidebar (#101022). High-contrast active states using Royal Blue.

The 'Drawer' Pattern

Secondary tasks like Document Uploads or Payment Details must never leave the current page context. Use Right Sidebar Drawers (overlays) to maintain focus.
